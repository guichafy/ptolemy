Para quem é

Feito para qualquer pessoa que usa um Mac

Se você troca de janela o tempo todo para abrir um app, fazer uma conta ou pesquisar alguma coisa, o Ptolemy encurta esse caminho para um atalho de teclado.

Para quem trabalha no computador o dia todo

Entre uma reunião e outra, abra o app certo, confira uma conta ou peça ao Claude para melhorar aquele e-mail, sem perder o fio do que estava fazendo.

  • Abrir o Zoom em um segundo
  • Revisar um e-mail com o Claude

Para quem estuda

Ferramentas

Cinco ferramentas, um único atalho

Já vem tudo instalado. Tab alterna entre as ferramentas e o que você digitou continua lá.

apps

Apps

Abra qualquer aplicativo

Digite as primeiras letras e aperte Enter. Safari, Zoom, Notas, Spotify: tudo o que está instalado no seu Mac, sem procurar no Dock ou no Launchpad.

Exemplo zoo → Enter
calc

Calculadora

Contas rápidas, na hora

Digite a conta e o resultado aparece enquanto você escreve. Enter copia o valor para colar onde quiser.

Exemplo 380 / 4 = 95
web

Busca Web

Pesquise sem abrir o navegador antes

Escreva o que procura e escolha onde buscar: Google, DuckDuckGo, YouTube ou Stack Overflow. O resultado abre direto no navegador.

Exemplo YouTube · receita de pão

Como instalar

Três passos e pronto

macOS 13 ou superior · Macs com chip Apple.

  1. 1

    Baixe a versão mais recente

    Um único arquivo .zip com o app, feito para Macs com chip Apple (M1 ou mais recente).

    Ver downloads
  2. 2

    Arraste para Aplicativos

    Abra o .zip e arraste o Ptolemy para a pasta Aplicativos. Na primeira vez, o macOS pede uma autorização em Ajustes do Sistema → Privacidade e Segurança.

  3. 3

    Aperte ⌘+Shift+Space

    O ícone aparece na barra de menu, no alto da tela. Daí em diante, o atalho abre a paleta por cima de qualquer app.

Perguntas frequentes

Antes de baixar

Preciso saber programar para usar?

Não. Basta baixar, arrastar para a pasta Aplicativos e apertar ⌘ + Shift + Space. Apps, Calculadora, Busca Web e Claude funcionam para qualquer pessoa; o plugin do GitHub é opcional.

Quanto custa?

Nada. O Ptolemy é software livre, distribuído sob a licença MIT.

Funciona no meu Mac?

Funciona em Macs com chip Apple (M1 ou mais recente) rodando macOS 13 Ventura ou superior. Macs com processador Intel ainda não são suportados.

O que preciso para conversar com o Claude?

Uma conta no Claude. Nas preferências do plugin, o próprio Ptolemy instala a ferramenta de linha de comando do Claude e abre a tela de login para você. Quem usa AWS também pode conectar um perfil do Bedrock.

Posso esconder as ferramentas que não uso?

Sim. Nas preferências você ativa, desativa e reordena os plugins. Quem não programa pode simplesmente desligar o GitHub.
